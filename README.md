## 📋 Project Overview

This capstone project guides students through building a real-world Call Automation application using:
- **Azure Communication Services** for calling capabilities
- **Azure AI Services** for Text-to-Speech and Speech-to-Text
- **Node.js/TypeScript** for backend development
- **Express.js** for web server
- **Azure DevTunnels** for webhook integration

### Learning Outcomes
- ✅ Cloud-based communication systems
- ✅ Azure services and APIs integration
- ✅ AI-powered voice interactions
- ✅ Production-ready telephony applications
- ✅ Agile development methodologies

## 👥 For Instructors

This project is designed for a 12-week academic semester with the following structure:
- **Weeks 1-2:** Foundation & Setup
- **Weeks 3-5:** Development Phase I (Core Implementation)
- **Weeks 6-8:** Development Phase II (Advanced Features)
- **Weeks 9-10:** Testing & Quality Assurance
- **Weeks 11-12:** Finalization & Presentation

See the [Capstone Project Plan](./CAPSTONE_PROJECT_PLAN.md) for detailed weekly breakdowns, assessment criteria, and grading rubrics.
